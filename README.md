# agent_RSI_demo

固定基础 LLM 权重，研究 Agent 如何利用执行反馈更新修订策略，并在**形式规划与符号发现**两个环境中检验同一更新机制。

**当前为研究设计与环境准备阶段。实验 Agent 调用为 0，尚无方法实现、正式实验或性能结果。** 仓库名中的 RSI 是项目简称，不代表已实现递归自我改写。
