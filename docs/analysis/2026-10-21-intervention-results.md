# 可执行干预检查：本轮结果与推断边界

本轮完成了两个研究者定义的局部检查：规划侧验证“只改输出空白是否足够”，符号侧验证“删除指定项并重新拟合，训练损失是否超过固定阈值”。它把此前只能保守返回未知的部分判断变成了有执行证据的有限结论，但还没有测试 Agent 能否主动提出、选择或利用这些检查。

范围固定为 Spanner seed0 的2个公开提示题、原2提示+8开发题，以及 oscillator1 的10000行训练表。没有读取或评分封存任务，没有更新模型权重或策略S，没有新增LLM请求。案例与阈值在看过历史开发结果后选定，随后才冻结本轮执行；不能称为盲选或独立确认。具体选择及操作顺序见[冻结协议](../protocols/2026-10-21-intervention-probes-v0.1.md)和[案例输入](../../artifacts/intervention-probes/2026-10-21/v01/cases.json)。

**符号检查固定了可被否定的命题，而没有泛泛地问“这一项是否有用”。** 本轮命题为：“删除指定新增项，并按固定协议重新拟合，使oscillator1/train NMSE增加超过ε=1e-5。”三版分别为归档原式、规范化完整式、删项式；三版均重新拟合，使用相同训练文件、全1初值和 `least_squares(max_nfev=100)`。完整式保留项的系数在删项后也允许重新优化，参数维度确实减少，因此不是简单把新增系数设零而固定其余系数。

两例都由窄AST契约确认：指定项拥有独立系数，删去它并重排参数后，其余项与归档父式同构。源码的比较本身不执行公式。训练表SHA-256为 `a846b36b931dee4e2335faf9fb4195a7a8d1b4e4430e915266ef45fcd2e07ee7`，本轮六次拟合均记录 `converged=true`，六次预测均在另一隔离进程完成。新数值来自本轮评价，旧分数没有充当新对照。

原式与完整规范式的NMSE差分别为0和 `1.3877787807814457e-17`，均小于 `1e-10` 的数值容差，未触发规范化漂移停止条件。两个Δ均为正；第一例大于 `ε+1e-10`，第二例小于 `ε−1e-10`。第二例判contradicted针对的是“损失超过ε”这个预先冻结的命题，**不是否定其正增益，更不是断言x⁵无用**。这与上一轮直接询问“是否有数值改善”的命题不同，不能把本轮阈值追溯套给上一轮。精确拟合参数、全部诊断和来源绑定分别保存在[v³探针记录](../../artifacts/intervention-probes/2026-10-21/v01/symbolic/p1-S-poly5-self/probe.json)与[x⁵探针记录](../../artifacts/intervention-probes/2026-10-21/v01/symbolic/p2-S-odd4-checked/probe.json)。

**两项的作用不同，是相对于各自保留基函数和本训练集的增量作用不同。** 第一例完整式为

```text
c1*x + c2*v + c3*x³ + c4*v² + c5*x⁵ + c6*v³
```

删项后保留 `x、v、x³、v²、x⁵`。新增的v³提供一个关于v的三次奇函数形状；它与已有的线性v和偶函数v²是不同的基函数。实际匹配拟合显示，即使其余五个系数全部重新调整，训练NMSE仍从约0.092249增加到0.093762。故在本表示、本数据和本优化协议下，保留v³有超过阈值的局部依据。对应源码见[完整规范式](../../artifacts/intervention-probes/2026-10-21/v01/symbolic/p1-S-poly5-self/canonical_full.py)与[删项式](../../artifacts/intervention-probes/2026-10-21/v01/symbolic/p1-S-poly5-self/removed.py)。

这不验证原候选注释中的全部物理故事。比如，完整式虽然总NMSE更低，但最高x分箱RMSE约0.025802，删项式约0.023388，前者在该箱反而更差；各箱并不是一致改善。最高v分箱RMSE只从删项式约0.029753降到完整式约0.029698。仅凭这些边际分箱和一个总损失差，不能证明“误差主要来自某种阻尼机制”“新增项纠正了全部高幅值行为”或数据的真实动力学一定包含v³。

第二例完整式为

```text
-k*x - c*v - d*x³ - c2*v*abs(v) - d2*x⁵
```

删项后保留 `x、v、x³、v*abs(v)`。新增x⁵细化了x方向已有的奇函数表示；保留式已经含线性x与三次x，也保留了非线性的 `v*abs(v)`。本轮实测表明，全部保留系数重新优化后，删除x⁵只付出约 `7.18e-7` 的NMSE代价，低于本轮允许的 `1e-5` 阈值，因此可以提出这个已实测的较简公式作为下一候选。对应[完整规范式](../../artifacts/intervention-probes/2026-10-21/v01/symbolic/p2-S-odd4-checked/canonical_full.py)与[删项式](../../artifacts/intervention-probes/2026-10-21/v01/symbolic/p2-S-odd4-checked/removed.py)明确显示了维度5→4。

不能进一步断言x⁵被其它项“完全替代”、样本中存在何种共线性或它在真实系统中不存在：本轮未分析设计矩阵秩、条件数、逐点反事实预测或独立数据。其拟合系数非零也不能单独证明重要性；不同变量、幂次和量纲下，系数大小不等于预测贡献。两案例的保留基函数不同，因此也不能从这两个Δ推出“v³通常优于x⁵”。

人工[耦合系数例](../../artifacts/intervention-probes/2026-10-21/v01/unsupported-fixture.json)为 `params[0]*params[1]*x + params[2]*v`。转换器因一项中存在两个耦合系数，返回 `unknown` 和 `term_requires_one_independent_coefficient`，没有生成可执行变体、没有运行候选。它校准的是工具不适用时的拒绝边界，不是基准中的第三个模型案例，也没有证据说这个公式本身正确或错误。

**下一步应先验证信息能否改变Agent的实际编辑，再研究主动选择检查。** 目前每个任务族只有一种检查算子：规划的空白规范化、符号的指定项删除。三个规划案例和两个符号案例提供不同输入状态，不等于同一状态下有多个可选择的检查。因此当前工具集合不足以测量“Agent会不会选择最有区分力的实验”，也不能把本轮人工门控当成自适应选择机制。

建议接入一个受控的两阶段流程：第一阶段，Agent基于固定起点提出有对象、范围、阈值和事前预测的局部假设，登记计划采取的编辑；随后按冻结工具契约执行检查。第二阶段，将检查结果绑定到原假设，再要求Agent决定保留、放弃或修订该编辑，并生成可执行候选。记录“假设—所需证据—观察—决策—源码变化—结果”的对应关系，而不只检查它是否复述了正确标签。原支持案例、矛盾案例和不适用案例都应保留，不能只接入容易成功的输入。

第一项对照应固定起点、模型、输入主体、可用工具与调用／执行预算，比较取得真实检查信息前后的编辑质量；可将同一第一阶段提交配对为“提供真实检查反馈”和“仅凭既有信息自行复查”。如果某分支看到了检查器生成的完整删项源码或可复制格式补丁，需要把效果限定为“额外检查产物与反馈的整体价值”，不能只归因于一个标签。比较时优先保存相同原始观察，明确哪些字段可见，测量错误编辑是否避免、合法局部收益是否保留、任务成绩与成本，而不以理由流畅度替代效果。

只有先建立这类信息效用证据，再为同一任务族、同一起点提供多个有不同成本与可区分假设的检查，才适合比较主动选择、固定日程或等预算选择。可考虑的扩展需要另立协议，例如规划中的格式检查与指定失败动作的前置条件检查，符号中的不同指定项删除或结构替换；这些在本轮均未实现或执行。当前结果可以支持“局部干预工具在已见案例上产生可解释的支持／矛盾／不适用结果”，尚不能支持“固定权重RSI已经能够可靠地自主选择实验并跨任务改进”。
