# 编辑声明与实际源码的一致性：离线协议 v0.1

本轮接续 decision-replay，研究固定模型权重下“证据—决策—实际编辑”的最后一个可检查环节。只读全部16份既有提交，检查窄编辑声明是否落实；不调用模型、不执行候选、不重新评价任务，不更新策略S，也不改变旧结果和标签。该协议在本轮离线分析前写入，但历史结果已经看过，不能称为前瞻预注册或独立评测。

## 输入与标注

- 输入固定为 `artifacts/decision-replay/2026-10-21/v01` 的303份原文件。先检查固定manifest哈希、完整文件集合和每个文件哈希，再重用上一轮只读审计复核请求、源码、任务、分数及执行账本绑定。
- 四个状态各2重复×2条件，全部纳入，按原运行次序，不按成功与否选取。已被研究者用于机制设计，重复生成不能充当独立任务样本。
- `configs/analysis/edit-consistency-v0.1.json` 是研究者事后标注：逐段读原rationale及已登记的auxiliary文本字段，选明确描述最终提交的句子；保留原JSON路径、文件SHA256、唯一引文和字符范围。程序仅验证引文来源，不自动理解自然语言，也不证明人工分类无偏。第二位审查代理交叉核对，仍不是独立人工标注者一致性实验。
- 普通keep映射为AST及参数元数据保持；只有明确byte-identical/verbatim才另加严格字节声明。缺少完整声明记not_stated；广泛语义修复记outside_supported_contract。不能用候选变化反推模型没有说过的意图。

## 静态检查的能力边界

所有候选仅作文本/AST解析，不import、eval、exec，不调用优化器、VAL或沙箱。源码上限16384 UTF-8字节，AST上限10000节点；不合法或不支持的源码返回unknown。原源码哈希等绑定失效则停止，不能悄悄给出结论。

1. `keep_bytes`：UTF-8字节及n_params相同。与性能、语义保持分开。
2. `keep_ast`：忽略位置后的完整AST及n_params相同。普通注释/空白忽略，docstring、类型注释仍参与；兼容Python3.10/3.12空type_params。TypeIgnore仅消除行位置、保留标签，不能据此认证类型检查注释的作用范围。此谓词是语法树投影相同，不是一般程序语义等价证明。
3. `apply_format_patch`：候选整树等于已有受限`build_format_patch`产生的整树，参数元数据不变。须真实发生约定格式变换；原样提交不能冒充修复；修改目标之外逻辑不通过。只能证明这一变换关系，不能证明函数被执行、输出被使用或任务成功。
4. `remove_selected_term`：原式和绑定父式满足已有受限线性参数项语法，目标和参数重编号正确；原/父式的导入、docstring、函数签名等外围不变；候选完整AST必须等于绑定父式。仅看目标字符串消失、系数归零、参数下降，或仅比较数学项签名均不够。更广的等价改写/别名改写、额外导入或副作用保留unknown，不声称数值等价。

每条窄声明输出supported / contradicted / unknown及理由。未知是检查能力边界；不把没有证据当作错误，也不把静态检查支持当作整段解释可信。旧`classify_edit`字段不改写，新关系作为附加观察。

## 部署假设与历史效果分层

P-format-r1-checked的keep声明和“host会自动处理边缘空白”是两件事。部署假设检查采用人工审查后绑定源码哈希的执行契约：`executor.py`将原`payload.plan`交给`planning.validate_plan`；后者先要求左括号后立即是操作符字母，再对已合格字符串进行strip/lower/split规范化。诊断probe对副本做的括号内边缘空白修复，并不发生在最终验证的严格语法门槛之前。不能笼统写host完全不做规范化。

契约绑定上述executor、planning和planning_probe三文件，并核对其与历史runtime-freeze一致。它是已审阅特定执行器的事实，不是自动推导任意运行环境行为的能力。其余因果解释、物理解释、最优性等保留未认证。

旧任务分数通过原候选SHA和原评价文件引用。只重算记录一致性，不重新运行候选或从预测原始数组独立重算NMSE。声明落实与是否值得做分开报告：保留声明可以为真而任务仍失败，删项落实也不意味着提高精度。

## 校准与可复核性

单元测试覆盖：真实16候选、换行与AST区别、格式补丁加逻辑修改、无修改冒充格式补丁、删错项/错参数数、额外导入/docstring/副作用、解析/长度/类型限制，以及引文/路径/哈希/目标篡改。人为构造用例仅为检查器校准，不能作为Agent任务成功率。

集成测试对已知网络、候选评价及沙箱入口设置禁止调用断言；这不是完整进程隔离证明。代码审查确认实际分析路径只有静态解析、文件读取和git show，不读数据标签或凭据。本机与服务器重新生成报告应逐字节相同。报告记录自身实现、测试、协议、标注文件哈希；历史303文件需保持不变。

本轮完成条件：窄检查器、原文可追溯标注、16份离线报告、边界/负例验证及双端复核全部完成后同步GitHub。下一阶段应将结构化编辑承诺前置于新提交，并把检查作为策略组件开展受控比较；不能凭本轮事后标注宣布策略学习有效、方法新颖或跨任务普适。
