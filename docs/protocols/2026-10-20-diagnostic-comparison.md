# 诊断观测与证据约束提示：开发对照 v0.1

日期：2026-10-20。依据上一轮实际轨迹与用户“继续完成下一步”的授权。本文件在本轮新模型请求之前冻结；属于探索性开发小试，不是预注册的正式统计检验。

## 研究问题与参照

比较新增诊断信息与新增修订提示规则的作用。CRITIC（ICLR 2024）、Self-Debugging（ICLR 2024）、llm-genplan（AAAI 2024）、Reflexion（NeurIPS 2023）及 LLM-SR（ICLR 2025）已经覆盖工具反馈、反思或候选迭代，不能将此循环本身称为创新。来源与具体证据另存文献核查说明。

| 条件 | 模型可见反馈 | 修订提示 |
|---|---|---|
| A | 原有状态、异常位置、开发分数 | 普通修订 |
| B | A 加固定诊断观测 | 与 A 相同 |
| C | 与 B 使用同一诊断生成规则 | 增加可证伪预测、证据引用、支持/反驳/不足的区分 |

B−A 用于观察信息增量，C−B 用于观察证据约束提示增量。后续候选不同，观测值自然不同；“相同诊断”指相同来源、探针、范围与计算规则，不保证整条轨迹内容相同。三组初始源码和初始观测须逐字节一致。C 是固定提示策略，不是自动正确的因果验证器；引用了观测只能证明引用存在，不能证明解释成立。

## 诊断接口

所有组都计算相同诊断，A 在向模型返回时隐藏，B/C 显示。这样诊断执行预算和额外探针开销相同。原始评价状态仍由 VAL/可信数值评分决定，诊断不能改写成绩。

规划只对两个 prompt 实例启用：

1. 可信外层按公开 STRIPS 语义重放实际输出计划，报告已执行动作数、首个失败动作、缺失前提、未满足目标；与 VAL 判定不一致属于设施错误。
2. 同一次候选执行中，记录有界的源码行命中次数与函数返回类型/容器长度摘要。只记录 candidate.py，不收集局部变量或字符串内容。最多 20000 事件、128 个不同源码行/函数项，超限明确截断；截断后的未命中不能作反证。
3. Python 轨迹来自隔离候选进程，可被候选干扰，不是抗恶意的可信评分证书。它只能帮助审查，不能取代 VAL；不声称可以由行轨迹自动证明因果归因。

符号在已有独立预测进程之后，由可信外层计算 prediction−target 的训练残差摘要：均值、RMSE、标准化偏差及每个输入的固定四分位分箱 count/mean residual/RMSE。分箱仅由训练输入确定，边界在候选间保持一致；只给聚合统计，不给逐行值。退化/空箱/溢出明确标记，不允许 NaN。关联统计不证明物理因果机制。

每份诊断绑定候选 SHA-256、任务 ID、诊断版本、数据范围；观测有稳定 ID。只允许固定 schema 的有界字段进入模型上下文，不能原样透传候选任意字典或 stderr。

## 本轮模型与预算

- MiniMax-M3、原有端点和 thinking-off 设置；OpenHands SDK 1.55.1。工具仍仅 submit_candidate/finish，不提供文件、终端或网络。
- 每会话最多三个生成候选、四次请求；共六会话最多 24 次请求，单次输出上限 4096 token、输入 JSON 上限 96 KiB。
- 新账本独立标识本轮，最多 3000000 保守计量 token、10 元费用预留，计入原项目 300 元预算。上一轮账本及未知费用不删除、不重置。本轮新增额度是新对照的额度，不是补跑旧小试以挑选好分数。
- 单价沿用本日已核验的输入 2.1 元/百万、输出 8.4 元/百万；估算与账单分开。
- 关闭自动重试。本轮任一 usage 缺失或设施失败，停止后续模型会话，不自动恢复、不更换模型或协议。完成的会话与缺失结果均报告。
- 固定执行顺序：planning_A、symbolic_C、planning_B、symbolic_A、planning_C、symbolic_B。顺序是事先安排的开发顺序，不声称随机化或消除了服务时间混杂。

候选仍按原开发分数选择 best，保存 initial/first/last/best 和全部失败。C 提示明确事实不足时保留不确定性；不会因为格式漂亮或诊断自信而加分。

正式机制实验仍需冻结未参与策略设计的新搜索状态、独立策略选择集、重复及效应指标。若本轮出现天花板、全部失败、协议不遵守或设施中断，应据实提出下一步，不能增加当前候选额度或事后调整停止规则。

Implementation bound fixed before model execution: an otherwise valid candidate trace above 20,000 serialized UTF-8 bytes is replaced by an explicit unavailable observation, preserving the trusted VAL verdict. This does not grant additional requests or diagnostic access.
