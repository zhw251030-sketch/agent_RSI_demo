# 共享假设、检查反馈与单次修订：开发协议 v0.1

## 问题与证据边界

固定 MiniMax-M3 权重和 OpenHands SDK 1.55.1。对于同一个已登记的局部假设，看到真实干预观测是否改变下一次实际代码编辑与开发成绩？本轮不训练权重，不更新持久策略 S，不评价自主选择检查，不声称新的 RSI 方法有效。

两个任务仍为 llm-genplan/Spanner 程序规划、原 LLM-SR/oscillator1 符号回归。四个真实历史状态：P-format-missing（paired-repair 的无括号动作字符串）、P-prefix（policy-transfer 的合法但不完整七步计划）、S-cubic（checked-feedback v01 的三次项追加）、S-square（v02 的二次项追加）。它们未用于上轮干预工具校准，但都是研究者已见的开发数据；S-cubic 是上轮 poly5 的祖先，S-square 曾作修订起点。不能写成新任务、盲测、独立泛化。

符号选择依据是现有窄 AST 删项契约能原样接纳的剩余真实历史 transition；规划保留一个工具契约不覆盖的格式错误与一个语义缺失案例。不会为获得阳性扩充检查契约。

## 冻结流程

1. 装载并校验历史源码、结果、诊断和 manifest 的固定 hash。模型看到当前源码/成绩/公开诊断与任务 API。符号另有父源码和选定项，隐藏父成绩及后继轨迹。旧记录不重跑或改分。
2. 四个状态各一次请求，工具 submit_probe 登记 probe_id、target_id，附预测、拟议编辑和理由。必需对象非法或没有工具提交记缺失；辅助预测错误单独分析，不撤销合法对象。预测不是工具结果。
3. 登记结束后，对合法登记各执行一次固定检查。规划检查两个公开题上同一 plan 的边缘空白规范化；不添加括号或动作。符号执行 original/canonical_full/removed 三次同训练集拟合，epsilon=1e-5、tolerance=1e-10。空白检查或删项契约不适用返回 unknown。epsilon 是既有工程阈值，不是统计显著性。
4. 冻结阶段一提交、真实请求/响应和完整检查结果。每个合法状态 fork 为 self、checked，各一次新会话、一次请求、至多一个候选。两臂共同拥有同一原始状态、同一登记、同一检查契约。只有 probe_feedback 不同：self=null，checked=白名单观测。checked 不得收到 plan、改写源码、拟合参数或现成下一步动作。
5. 修订固定交错顺序：P-format-missing/self、S-cubic/checked、P-format-missing/checked、S-cubic/self、P-prefix/checked、S-square/self、P-prefix/self、S-square/checked。不补抽、不重试、不按结果改序。已知 usage 的结构性缺失允许其他独立槽位继续；未知/无效 usage、未结算请求、预算 halt 或基础设施错误全轮停止。
6. 每个规划候选评价原两公开题和八开发题；每个符号候选仅训练集拟合与预测。封存集调用为零。所有模型代码只在既有隔离执行器中运行。

## 公平性、计数与结果

各会话最多一次请求，统一4096输出token、98304完整请求字节，12会话不超过1600000保守预留token、5元预留费用。使用已有每百万输入2.1/输出8.4元预算口径，不冒充供应商最新账单价格；全部预留不退回。共享阶段一费用单列，两臂各4个修订机会。请求次数/上限相同不等于实际输入token相等。

实际保存的 SDK 发送前请求封装，除 user packet 的唯一 probe_feedback 字段外须完全一致；不忽略 system、tools、模型配置或其他状态。不能称独立捕获的 HTTP 报文相同。

最多54任务级评价/生成、64sandbox：检查4次规划生成+6次符号评价（16sandbox），修订40次规划+4次符号评价（48sandbox）。最多48次宿主规划验证、VAL≤48；宿主预检拒绝不计VAL。每次执行先持久化预留，记录已确认实际次数；无法确认则注明下界并停止。

规划主指标是8开发题成功数，另列2公开题；符号报告train NMSE和参数数，分别判断严格误差改善（下降>1e-10）和可接受简化（参数减少且NMSE增量<1e-5，距离阈值≤1e-10记边界不确定）。每族单列，不合成跨族总分。缺候选连续成绩为null，不能填父分数。只有两臂均有完整结果才计算连续配对差，完整案例选择的局限随结果说明。

事后只做静态源码编辑分类及登记预测核对；不把理由自述当因果证据。四个状态、每臂一次随机输出只能支持接口与个案机制诊断，不能支持稳定优势、统计显著性或独立泛化。

## 归档

运行前提交协议、配置、实现与测试，三处同步后冻结Git版本/运行源文件。运行产物独占新目录，不恢复旧轮。完整原始记录逐字节归档，报告核查输入投影、源码绑定、预算、指标和缺失；记录审计不冒充任务重跑或原始预测的独立重计算。
