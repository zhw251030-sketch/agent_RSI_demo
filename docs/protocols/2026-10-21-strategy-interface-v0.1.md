# 策略实验接口与无模型验收 v0.1

本轮承接已冻结的 state-generation v02 八份源码和 strategy-pair-allocation v0.1 的36请求分配，完成执行权限、旧学习材料、提示与真实记录投影的接口。用户的继续指令覆盖此实现及验收。模型权重、八条规则目录、S0、任务划分、收益阈值和36槽顺序均不变。

## 本轮边界

本轮不发模型请求，不执行八份新起点，不拟合选择或评价方程，不产生S1或S*。完整模型实验仍须有经真实SDK模拟验证的调度器，把本轮接口、预算、停止条件和冻结顺序连接起来。本轮不把配置中的 execution_ready 改成 true。服务器隔离校准只允许手写源码和临时人工数据；不能将此分数记为真实任务成绩。

## 结构和实现顺序

1. `rsi_eval/role_executor.py`：读取已冻结角色元数据；先验证权限再读取任务文件。学习角色仅原10个Spanner和oscillator1，选择角色仅19个Spanner和oscillator2，评价角色仅63个Spanner和bactgrow/stressstrain；原官方测试永不开放。沿用既有sandbox、任务工作进程和VAL，不改旧模块权限。
2. `rsi_eval/strategy_learning.py` 与 `prompts/strategy-pair/`：建立新版学习包，覆盖 decision-replay 16份和 edit-commitment 8份历史终稿，包含允许范围的来源、观测、声明和结果。只用这两个完整旧批次，不以收益筛选，不声称覆盖所有历史实验。其底层任务仅seed0和oscillator1。静态后置分析、v02源码、选择/评价反馈不进入学习包。
3. `rsi_eval/strategy_binding.py`：从实际请求文件、策略内容、原始候选与执行收据构造 goal_alignment.select_strategy 所需记录。校验完整分配及来源；不能仅给一个自报分数或重新计算了哈希的对象就当作真实测量。两次提案分别选择，两个结果都必须冻结后才开放评价。
4. 准备脚本：只读验证既有源码归档和角色元数据，冻结完整学习包、更新提示、输入来源与运行文件清单；记录尚缺的真实运行环节，不制造空白测量或假策略结果。

## 学习与策略内容

S仍是现有8条通用规则中有序选择4条。新版学习包不冒充旧控制器只支持U-P/U-S两张经验卡的格式；后续SDK控制器必须明确使用新版接口。模型自由解释、支持理由和shadow提案仅归档，不进入修订策略。actor只得到宿主渲染的选中规则、共同任务信息、共同起点及允许反馈；不获得其他提案或学习过程全文。

两次updated提案及两次shadow请求使用相同学习信息和请求额度。它们是同一学习材料上的请求重复，不是两个独立学习数据集。禁止从两个updated提案中择优，仅分别报告各自选择及后续结果。

## 反馈与评分权限

规划修订反馈继续仅来自原seed0的10个学习题，其中两个为旧公开例题；19个选择题、63个评价题的结果只供宿主评分，不回传同次修订。符号反馈来自对应阶段方程的train拟合，所有test_id/test_ood仍封存。新评价起点的任何基线/反馈构建，包括在学习题上运行评价规划程序，也必须等两个S*都冻结。

任务角色权限与起点阶段权限是两道不同约束：在学习题上运行评价起点仍是评价阶段活动。未来调度器必须同时验证它们，不能通过换task role绕开S*冻结顺序。

## 原始测量与接受

每条测量绑定源码字节、参数数、任务ID、数据哈希、执行器文件、策略、请求和反馈上下文。符号n_params按模型声明计，是复杂度代理，不能解释成已认证的可辨识参数维数。真实执行中的缺失、超时、候选错误与基础设施失败分别保留；符号无完整数值成绩时不做凭空的NMSE比较。

r1和r2分别创建4状态的选择分配，每个只含该重复对应的固定/更新终稿。调用既有接受器比较两臂最终产物，不能用“各自相对基线的改善标签”代替直接比较。任何退化或不确定阻止晋级，至少一项严格收益才晋级。S1被拒后S*=S0；同策略随机差异不是S更新收益。

哈希和回放验证提供可信客户端范围内的一致性；不是供应商签名、可信硬件执行证明或独立时间戳。真实运行还须核对SDK业务提交和实际发送请求，并在首请求前冻结协议及运行版本。

## 验收

测试先覆盖错误权限、错任务/源码/数据/策略/请求、缺失与重复测量、两次选择尚未齐全、路径逃逸和篡改。使用独立人工预期验证收益选择，不能只让实现自算预期。服务器临时人工任务校准真实sandbox/VAL和符号拟合/独立预测；本机以离线逻辑测试为主。两端重建准备产物并比较哈希；旧记录和旧运行文件保持字节不变。最终同步私有GitHub与服务器，费用累计保持上一轮数值。
