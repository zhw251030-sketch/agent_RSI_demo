# 任务数据准备与验收

用户已要求下载两条路线的任务并继续准备；随后明确要求用可公开下载的相近数据替代访问困难的 LLM-SRBench。本工作单元落实数据获取、加载检查和固定验证器样例，不启动模型实验。

1. 核查本机、GitHub 与服务器 Git 状态，固定官方源码 commit、下载包 SHA-256 和每个数据文件的哈希。
2. 规划保留 llm-genplan 的 Spanner：100 个训练问题、300 个测试问题与一个域文件。保持现有 seed0 2/8/30 准备稿，不在此次运行测试集成绩。
3. 符号侧改用原始 LLM-SR 的公开四任务包，先以 oscillator1/2 起步；保留官方 train/test_id/test_ood。它不是 LLM-SRBench，不能沿用后者的题数、列顺序或论文结果。
4. 源码保存在被 Git 忽略的 vendor/，选定数据复制到 data/；下载脚本、版本清单和去除原始数据的验收结果纳入版本管理。保留上游许可证。
5. 规划逐文件核对并在一个公开 prompt 样例上测试 VAL 的正确计划、空计划、前置条件错误和缺失程序分类。符号侧检查 CSV 列名、数值、行数、重复和划分重叠；不拟合测试集。
6. 记录运行结果、限制与下一步，提交推送并通过 Git bundle 快进同步服务器。

验收范围：数据可获得且字节一致，规划验证器能在此机器正确分类固定样例，符号数值可解析。正式 PDDL 解析器、公式参数拟合器、Agent 工具接入、生成代码隔离、策略选择集与研究评价仍是后续工作。下载和准备验收不收费调用模型。
