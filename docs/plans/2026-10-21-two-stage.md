# 两阶段开发实验实施计划

已有用户继续实现、API复用、300元总预算及持续Git同步授权。本工作单元预算5元，最多12请求，不恢复旧实验。

1. [ ] 在不修改历史冻结模块的前提下新增四状态严格装载器，测试hash和信息投影。
2. [ ] 新增登记/修订控制器、反馈白名单与完整请求配对审计；使用假执行器测试调用限制、缺失、基础设施错误和指标边界。
3. [ ] 新增SDK两阶段单请求工具适配，真实SDK+mock provider验证工具结构、空提交、usage停机和输入封装。
4. [ ] 新增串行运行器、持久执行预算、阶段冻结与只读审计；测试伪造冻结、预算越界、请求不一致。
5. [ ] 本机与服务器检查，提交并同步后冻结运行版本。prepare-only零API，正式最多12API。
6. [ ] 保存所有结果，包括unknown、失败与无候选。逐字节归档、事后审计、中文说明及状态更新。
7. [ ] 检查私密内容边界，提交/推送，服务器fast-forward，核验三处一致并交付。
