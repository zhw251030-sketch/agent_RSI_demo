## 约束

不更改系统 Python、已有 conda 环境或 Docker 权限。环境安装可使用公共官方包源；本轮不申请受限数据访问、不配置 API 凭据、不启动模型调用。

无模型检查只执行人工写定的小脚本，不执行模型生成代码。Python 虚拟环境只隔离依赖，不隔离文件、网络或系统权限；在隔离执行环境就绪前，不能将本次工具检查当作任意候选程序的执行许可。

研究接口文件是本轮可审查产物。规划域和符号子集沿用此前建议，但具体机制、基线参数和正式实验协议仍需要后续工作落实。
