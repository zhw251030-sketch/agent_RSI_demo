# OpenHands 网页入口部署计划

用户已确认继续部署官方 Agent Canvas。目标是可从本机浏览器访问服务器上的项目，并保留已有 SDK 环境用于可重复实验。

执行状态：已完成安装、网页目录选择、HTTP/监听/停止重启验收；结果与限制见 [部署记录](../environment/2026-10-20-canvas-deployment.md)。

## 范围与选择

- 使用官方 npm 发布包，固定版本；复用服务器已有 Node.js 24，单独安装 uv 和网页运行依赖。
- 项目状态与运行依赖使用被 Git 忽略的独立目录，避免混入历史 OpenHands 配置或改变实验 `.venv`。
- 服务只监听服务器回环地址，本机通过 SSH 转发访问。已有 8000、3000 端口不占用；预选 18080。
- 在网页确认后端连接，并选择本项目目录。跳过模型和自动化配置，不发送 Agent 消息。
- 验证进程、端口、HTTP 和实际页面；提供启动、停止、访问说明以及脱敏记录，提交并同步三处 Git。

## 验收边界

网页可用不等于模型已连接、任务执行器已完成或正式实验已有结果。直接本地后端不是生成代码沙箱；隔离执行仍是后续实验接入的前置工作。
